# Fonts

`NotoSansSC-subset.ttf` is a subset of [Noto Sans SC](https://github.com/google/fonts/tree/main/ofl/notosanssc) (weights 400–700), limited to the characters `examples/comparison.ts` uses so it stays small. Copyright 2014–2021 Adobe (http://www.adobe.com/), with Reserved Font Name 'Source'. It is licensed under the SIL Open Font License 1.1 (full text in [`OFL.txt`](OFL.txt)), and it is a Modified Version as the license defines.

To use other Chinese text, regenerate the subset with fontTools (`pyftsubset`), or point `fonts` at a full CJK font.
